# 离线展示系统终端配置文件 (config.json) 使用指南

在同级目录下，`config.json` 是本离线大屏触摸展示系统的全局核心运行配置文件。
您可以通过修改其中的参数，轻松控制整个应用的**屏幕分辨率**、**全屏展示行为**以及**信息亭锁定模式 (Kiosk)**。

---

## ⚙️ 配置文件参数说明

配置文件中目前包含以下三个核心配置项，它们必须以**标准 JSON** 的格式定义：

```json
{
  "resolution": "1920x1080",
  "kiosk": true,
  "fullscreen": true
}
```

### 1. `resolution` (屏幕分辨率)
*   **作用**：设置 Electron 主窗口的物理画布大小。
*   **可选参数**：支持任意标准物理分辨率，官方优化推荐：
    *   `"1920x1080"` (默认分辨率/1080p 标准一体机)
    *   `"2560x1440"` (2K 高清屏/画廊级展示)
    *   `"1680x1050"`
    *   `"1440x900"` (常用笔记本调试环境)
*   **兜底策略**：如果此项留空或配置文件缺失，系统将自动采用默认的 `"1920x1080"` 进行加载。

### 2. `kiosk` (亭机锁定模式)
*   **作用**：是否启用大屏专用亭机（Kiosk）锁定模式。
*   **可选参数**：
    *   `true` (**推荐生产部署值**)：强制全屏且顶层独占展示，彻底隐藏操作系统的鼠标指针（视设备而定）、系统任务栏和系统快捷键窗口切换（屏蔽 Alt+Tab、Alt+F4 等），防范访客退出应用，适合商场/展馆一体机部署。
    *   `false`：普通窗口形态，适合本地调试。

### 3. `fullscreen` (全屏模式)
*   **作用**：是否全屏拉伸展示。
*   **可选参数**：
    *   `true`：窗口直接全屏覆盖系统桌面（不保留边框和窗口标题栏）。
    *   `false`：作为独立的窗口渲染，配合 `kiosk: false` 可以在个人电脑上方便拖拽。

---

## 💻 场景配置推荐

为了获得最佳的体验，我们为您推荐以下两套典型场景的配置组合：

### 场景 A：触摸大屏/展馆一体机部署 (生产环境)
在此模式下，系统将获得最高的权限，锁死操作系统，确保大屏展示纯净且无法被外部访客退出：
```json
{
  "resolution": "1920x1080", // 或根据大屏实际物理像素改为 "2560x1440"
  "kiosk": true,
  "fullscreen": true
}
```

### 场景 B：本地开发与多分辨率自适应调试 (开发环境)
在此模式下，主进程会极其智能地自动剥离锁定，**为您提供正常的操作系统标题栏和边框，并允许自由拉伸窗口大小**。您可以非常直观地拖拽检验各分辨率自适应排版是否完美：
```json
{
  "resolution": "1920x1080", // 此时可改为您任意想模拟测试的目标分辨率
  "kiosk": false,
  "fullscreen": false
}
```

---

## ⚠️ 注意事项
1. **语法合规**：因为该文件为标准 `.json` 格式，**请勿在此 `config.json` 文件内编写带有 `//` 或 `/* */` 的注释**，否则会产生 IDE 红线。所有的配置参数说明已在本 `README.md` 中为您详细呈现。
2. **管理员强行退出快捷键**：在任何配置（包括 `kiosk: true` 全锁死模式下），管理员均可通过在键盘上按下 **`Ctrl + Alt + Q`** 组合键来安全退出并关闭本展示程序。

# 素材数据文件 (data.json) 维护指南

`data.json` 是本展示系统的素材数据清单，定义了所有主题及其下属素材的元信息。新增或修改素材时，需同时操作**素材文件**和 **`data.json` 数据记录**。

---

## 📁 目录结构

```
resources/
├── images/
│   ├── covers/       ← 封面缩略图（所有素材都需要）
│   ├── materials/    ← 图片类素材的正文大图
│   └── themes/       ← 主题背景图（一般不需要改动）
├── videos/           ← 视频类素材文件
├── audios/           ← 音频类素材文件
├── data.json         ← 素材数据清单（本文档重点）
└── config.json       ← 系统运行配置
```

---

## 📝 新增素材操作步骤

### 第一步：将素材文件放入对应目录

根据素材类型，将文件放入相应目录：

| 素材类型 | 正文文件存放位置 | 封面图存放位置 |
|---------|----------------|--------------|
| 文本 (text) | 无需文件，正文直接写在 `data.json` 的 `content` 字段中 | `images/covers/` |
| 图片 (image) | `images/materials/` | `images/covers/` |
| 视频 (video) | `videos/` | `images/covers/` |
| 音频 (audio) | `audios/` | `images/covers/` |

> **封面图**是列表页展示的缩略图，所有类型的素材都必须提供。

### 第二步：在 data.json 的 materials 数组中添加记录

打开 `data.json`，在 `"materials"` 数组末尾添加一条新记录。完整示例：

```json
{
  "id": "sm-004",
  "theme": "shuimitao",
  "title": "桃文化诗词集",
  "author": "某某某",
  "type": "text",
  "category": "乡土人文",
  "region": "溪口",
  "period": "古代",
  "cover": "images/covers/sm-004.jpeg",
  "content": "这里直接写正文内容，支持用 \\n 换行。",
  "tags": ["水蜜桃", "诗词", "文化"]
}
```

---

## 📋 materials 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | 素材唯一标识，格式为 `前缀-三位数字`，见下方 ID 命名规则 |
| `theme` | 是 | 所属主题，必须与 `themes` 数组中的 `name` 一致 |
| `title` | 是 | 素材标题 |
| `author` | 是 | 作者名称 |
| `type` | 是 | 素材类型：`text` / `image` / `video` / `audio` |
| `category` | 是 | 分类标签，如"乡土人文"、"文艺艺术"、"非遗技艺"、"自然山水" |
| `region` | 否 | 所属地区，如"溪口"，无特定地区可留空 `""` |
| `period` | 是 | 时期：`古代` / `近代` / `当代` |
| `cover` | 是 | 封面图路径，统一以 `images/covers/` 开头 |
| `content` | 是 | 素材正文（见下方对照表） |
| `tags` | 是 | 搜索标签数组，用于模糊搜索，建议 2-4 个 |

### content 字段与类型对照

| type | content 字段填写方式 |
|------|---------------------|
| `text` | 直接写正文文字，换行用 `\n` |
| `image` | 图片路径，如 `images/materials/sm-002.jpeg` |
| `video` | 视频路径，如 `videos/sm-003.mp4` |
| `audio` | 音频路径，如 `audios/ml-003.mp3` |

---

## 🏷️ ID 命名规则

ID 由 **主题前缀** + **短横线** + **三位序号** 组成：

| 主题 | 前缀 | 示例 |
|------|------|------|
| 水蜜桃 (shuimitao) | `sm` | sm-001, sm-002 |
| 弥勒 (mile) | `ml` | ml-001, ml-002 |
| 蒋氏故里 (jiangshi) | `mg` | mg-001, mg-002 |
| 布龙 (bulong) | `fy` | fy-001, fy-002 |
| 其他 (other) | `sy` | sy-001, sy-002 |

> 如有新的主题类别，自行拟定 2-3 位英文前缀，保持全局唯一即可。序号从 001 递增，不要跳号或重复。

---

## ⚠️ 注意事项

1. **JSON 语法**：`data.json` 是标准 JSON 文件，**不允许使用注释**（`//` 或 `/* */`）。所有逗号、引号、括号必须配对正确，建议使用带 JSON 语法检查的编辑器（如 VS Code）。
2. **路径写法**：所有路径均为**相对于 `resources/` 目录的相对路径**，使用正斜杠 `/` 分隔，不要以 `/` 开头。
3. **封面图尺寸**：建议封面图统一裁剪为 **16:9** 比例，分辨率不低于 **800×450** 像素，以保证列表页显示清晰。
4. **视频格式**：推荐使用 `.mp4` (H.264 编码)，兼容性最好。
5. **音频格式**：推荐使用 `.mp3` 格式。
6. **新增主题**：如需新增主题，除在 `themes` 数组中添加记录外，还需在 `images/themes/` 下放入对应的背景图。
