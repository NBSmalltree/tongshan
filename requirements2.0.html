在地文化数字共创平台

全周期业务需求说明与落地规划文档

汇报人：项目技术团队

核心架构：一库多端

时间：2026 年 5 月

总体建设路线：三步走演进战略
Tongshan Academy • Roadmap

为降低政企项目演进风险、快速建立信任，项目整体采取“离线先行、云端共创、商业闭环”的三阶段敏捷落地模式：

第一阶段：效果与离线屏显 10人天

纯线下环境交付，快速上线

  • Windows 离线大屏机专属独立包
  • Electron 本地沙箱离线隔离架构
  • 完成“开屏+5大主题+模糊检索”
  • 预埋图文音视频全要素多媒体素材

第二阶段：云端迁移与数字共创 18人天

打破孤岛，实现社会级协同

  • 迁移数据至阿里云(ECS+RDS+OSS)
  • Spring Boot 3 + MyBatis-Plus
  • 微信小程序多角色(美协/学协等)登录
  • 创作者端 UGC 资源异步上传与流式审核

第三阶段：价值变现与文化生态 15.5人天

实现数据与商业闭环可持续运营

  • 积分账本与高并发防超卖库存事务机制
  • 小程序文创农特产商业微信支付商城
  • 大屏联网升级，引入交互核销二维码
  • 打通线上赚积分、线下兑好礼物理闭环
一阶段：线下离线全屏展示系统需求
Phase 1 • Electron 独立可执行程序方案
需求编码 细分功能名称 业务规则与业务描述 计划人天
F1.1 离线运行环境与安装包打包 采用 Electron 技术栈，将纯前端 Vue 3 系统编译封装为 Windows 环境下免配置双击直接运行的独立安装包（.exe）。 1.5 人天
F1.2 全屏看门狗开屏欢迎页 支持设定自动进入 Kiosk 屏显全屏模式。从本地相对路径读取图片执行滚动轮播，点击屏幕任意位置优雅淡入主界面。 1.0 人天
F1.3 风格主题检索书册排版 主界面采用“电子书册/画廊”排版风格。设立水蜜桃、弥勒、民国、宋韵、非遗 5 大主题入口网格。 2.0 人天
F1.4 多媒体离线详情画廊与全屏放大 点击特定主题跳转二级列表。支持再次点击素材触控全屏放大。集成高性能离线原生组件，支持图文、音频、高码率视频的独立流畅播放。 2.5 人天
F1.5 本地内存级模糊搜索框 在顶端常驻搜索框。支持输入作品名、作者名、风格标签。利用前端内存对预埋 JSON 数据进行秒级模糊匹配，并以列表框瀑布流展示结果。 1.5 人天
F1.6 离线素材结构化预埋组织 规范化大屏机本地静态存储路径。对非遗原始长视频、大图完成标准化转码和压缩。通过 data.json 预埋结构化演示资产。 1.5 人天
二阶段：云端迁移、后台管理与共创小程序
Phase 2 • 云端数字底座与 UGC 协同协同
需求编码 细分功能名称 业务规则与业务描述 计划人天
F2.1 阿里云基础设施搭建与联调 采购并配置华东节点 ECS 算力源、内网直连 RDS MySQL 数据库及公共互联网去中心化对象存储 OSS。完成 HTTPS 证书绑定。 2.0 人天
F2.2 Java 核心后台架构设计 基于企业级 Spring Boot 3 + MyBatis-Plus。设计文化资源全生命周期资产表、组织权限RBAC模型。产出大屏与小程序共用的标准 RESTful API。 3.5 人天
F2.3 书院资产 CMS 后台管理 提供给书院管理员的数据维护后台。包含资源增删改查；支持多媒体文件直传阿里云 OSS。主页展示资源存储总量与分类统计大屏看板。 4.0 人天
F2.4 多角色微信授权认证体系 微信小程序对接原生生态登录。在系统内部划分：美协、书协、作协、在地艺术家、在校学生等不同共创权限组。 2.5 人天
F2.5 小程序移动端文化多维查询 复刻一阶段大屏的检索逻辑至移动端，适配手机单手触控、列表上拉加载、下拉刷新以及检索词防抖（Debounce）处理。 2.5 人天
F2.6 UGC 在地共创移动端投稿 共创核心。各协会成员或学生可通过小程序直接撰写描述、打风格标签、并上传拍摄的非遗视频/音视频至云存储，状态默认置为“待审核”。 3.5 人天
三阶段：积分商城与文化生态变现
Phase 3 • 微信支付电商与线下联动核销
需求编码 细分功能名称 业务规则与业务描述 计划人天
F3.1 交易安全底座与积分账本 设计严格的积分扣减、商品库存冻结机制。采用数据库行锁或 Redis 分布式锁，确保并发场景下（如抢兑活动）绝对不发生“超卖”和乱账。 3.0 人天
F3.2 微信支付文创及农特产商城 开通微信支付企业商户。小程序端上线书院文创产品、奉化水蜜桃特产等实体/电子版权商城，打通微信原生安全支付闭环。费率按官方 0.6% 结算。 4.0 人天
F3.3 用户积分任务与权益商城 用户通过共创投稿被采纳、每日打卡等获得积分。设立专门的“积分兑换区”，消耗积分可兑换书院线下实体小礼品，兑换成功生成专用加密核销二维码。 2.5 人天
F3.4 线下大屏联网升级与扫码联动 一阶段大屏机接入网络，升级增加“扫码联动”板块。大屏实时拉取云端礼品池。游客在屏幕点击兑换，大屏展现对应二维码，用户用小程序扫码完成扣点。 3.5 人天
F3.5 订单流转与账目审计系统 后台提供完整的订单发货流程追踪、线上真实支付对账单下载、线下大屏核销网点流水审计，保障资金流与资产物流合规。 2.5 人天
