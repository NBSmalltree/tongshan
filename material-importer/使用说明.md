# 素材导入工具 — 使用说明

## 一、安装工具

### 方式一：Windows 安装版

1. 下载 `素材导入工具_1.0.0_x64-setup.exe`
2. 双击运行，按照提示完成安装
3. 安装完成后，桌面会生成快捷方式

> 如果安装时提示"需要 WebView2 运行时"，说明系统缺少运行环境，请先安装 WebView2 Runtime（离线安装包见附件或联系技术人员），安装完成后再重新安装本工具。

### 方式二：Windows 便携版

1. 下载便携版 exe 文件（文件名含 `portable`）
2. 无需安装，双击直接运行

---

## 二、准备素材文件

在导入前，请将所有素材文件放在一个文件夹中，并**严格按照以下格式命名**：

```
作品名+作者1_作者2_作者3+类别+标签1_标签2.扩展名
```

### 各部分含义

| 部分 | 说明 | 示例 |
|------|------|------|
| 作品名 | 素材标题，直接写中文 | 蒋氏故居一角 |
| 作者 | 用 `_` 连接多个作者 | 张三_李四_王五 |
| 类别 | 素材分类 | 文艺艺术、乡土人文、非遗技艺、自然山水 |
| 标签 | 用 `_` 连接多个标签 | 民国_建筑_溪口 |

### 完整示例

```
蒋氏故居一角+张三_李四_王五+文艺艺术+民国_热闹_建筑.jpg
奉化水蜜桃+张明远+乡土人文+水蜜桃_传说_南宋.txt
桃园春色+李晓华+自然山水+桃花_春天_溪口.png
雪窦寺钟声+赵宇飞+文艺艺术+雪窦寺_钟声_禅意.mp3
布袋和尚的故事+刘文静_冯雅芝+乡土人文+弥勒_布袋和尚_雪窦寺.txt
```

### 支持的文件类型

| 类型 | 支持的格式 | 说明 |
|------|-----------|------|
| 图片 | jpg、jpeg、png、gif、bmp、webp、svg、tiff | 自动复制到 resources/images/materials/ |
| 视频 | mp4、avi、mov、mkv、wmv、flv、webm | 自动复制到 resources/videos/ |
| 音频 | mp3、wav、ogg、aac、flac、wma、m4a | 自动复制到 resources/audios/ |
| 文字 | txt、md、rst | 文件内容直接写入配置，不复制文件 |

## 三、操作步骤

### 第一步：打开工具

双击桌面快捷方式（或便携版 exe）打开素材导入工具。

### 第二步：选择配置文件

点击 **data.json 路径** 旁的「浏览」按钮，选择 `stage1/resources/data.json` 文件，然后点击「加载」。

加载成功后，左侧面板会显示当前所有素材的结构树和 ID 统计。

### 第三步：选择素材文件夹

点击 **素材文件夹** 旁的「浏览」按钮，选择你准备好的素材文件夹，然后点击「扫描」。

扫描完成后：
- 符合命名规范的文件会显示在右侧预览表格中
- 不符合规范的文件会弹出告警窗口，列出具体是哪些文件有问题

### 第四步：设置导入参数

- **ID 前缀**：输入新素材的 ID 前缀（如 `sm`、`ml`），工具会自动从现有最大序号递增
- **所属主题**：选择这些素材属于哪个主题

> 主题前缀对照表：shuimitao → sm，mile → ml，jiangshi → mg，bulong → fy，other → sy

### 第五步：执行导入

确认预览表格中的文件无误后，点击「执行导入」按钮。

导入完成后，左侧结构树会自动刷新，显示新增的素材。

## 四、常见问题

### 1. 扫描时提示"文件名不符合规范"

检查文件名是否严格按照格式：`作品名+作者+类别+标签.扩展名`，各部分之间用 `+` 号连接，多个作者和标签之间用 `_` 连接。

### 2. 导入后图片/视频没有显示

确认文件格式是否在支持列表中（见上方文件类型表格）。不支持的文件格式会被自动跳过。

### 3. ID 前缀应该填什么？

根据素材所属主题填写：
- 水蜜桃相关 → `sm`
- 弥勒相关 → `ml`
- 蒋氏故里相关 → `mg`
- 布龙/非遗相关 → `fy`
- 其他 → `sy`
- 作品展示类 → `cszp`

### 4. 可以重复导入同一批素材吗？

可以。工具会根据 ID 前缀自动递增序号，不会影响已有的素材。但如果同一批文件已导入过，会产生重复记录，需要手动在 data.json 中删除。

### 5. 工具界面显示乱码

请确保 Windows 系统语言设置为中文，或使用支持中文的系统字体。
